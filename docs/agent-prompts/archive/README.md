# Agent Prompt Archive

This folder contains historical prompt docs, experiments, and planning notes that are no longer part of the active pipeline documentation.

Active prompt docs live in the parent directory:

- `AGENT_PROMPT_SHARED.md`
- `AGENT_PROMPT_NEW_APP.md`
- `AGENT_PROMPT_IMPROVEMENT.md`

Archived files are kept for reference only and should not be treated as the current source of truth for agent workflows.
